## MANDATVM / MISSION

Artifex Ignotus builds compact, inspectable tools for defensive security, authorized research, and the careful interpretation of exposed technical signals. The work centers on software behavior, provenance, and the limits of what evidence can establish.

The workshop exists because defensive decisions are stronger when sources, assumptions, and methods can be examined independently. It favors narrow claims, reproducible records, and local processing where practical, keeping uncertainty visible instead of burying it beneath confidence.

## AREAE OPERIS / FOCUS

- **Repository assurance and software supply chain hygiene.** Security hygiene around source history, automation boundaries, release surfaces, dependencies, and supply chain evidence.
- **Defensive intelligence and evidence-led OSINT.** Research that preserves provenance, distinguishes observation from inference, and keeps authorization explicit.
- **Local-first privacy and software behavior verification.** Privacy-conscious inspection of software behavior and artifacts, keeping processing close to source data where practical.

## IN OFFICINA / CURRENT WORK

CLAVIS is currently in private alpha and is not publicly available. It is being developed within the workshop’s local-first, defensive, and authorized-use mandate; no public capability or release claim is made.

## PRINCIPIA / ENGINEERING STANDARD

| Standard | Practice |
| --- | --- |
| Authorization | Scope is explicit before collection, inspection, or testing. |
| Locality | Processing stays local and retained data is minimized where practical. |
| Evidence | Methods, assumptions, limitations, and provenance remain inspectable. |
| Restraint | Defensive value takes precedence over breadth, novelty, or display. |

Public claims follow only publicly verifiable evidence.
